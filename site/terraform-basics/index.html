Terraform Basics

What is Terraform?

Terraform is an Infrastructure as Code (IaC) tool by HashiCorp.


Why Terraform ?

Suppose you are the Devops engg wherein you get the request of creating a single Ec2 instance for which you login to AWS Console & spawn a EC2 Instance which usually take 2-5mins, let's say you got of 50-100 request for Ec2 instance's considering a lot of time will be spent creating manual instance's and margin of error will be high as well. So Nowadays most of the cloud providers has their own set of automation tools for example AWS has CloudFormation Template (CFT), while Azure has ARM Template, Biceps, so learning this tools for every provider & memorizing it's not easy at all. So Terraform is an Unified platform for Multiple providers where in it has multiple provider support for all cloud's. With Terraform you can provision infrastructure as a code IAC within minutes that too in a specific desired state.
